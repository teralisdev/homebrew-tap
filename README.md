# Teralis Homebrew tap

```sh
brew install --cask teralisdev/tap/vitrel
```

| Cask | What |
|---|---|
| `vitrel` | [Vitrel](https://vitrel.app), a minimal web browser for macOS built on WebKit. macOS 15.4 or later. |

Vitrel's alpha builds aren't signed with a Developer ID yet, so macOS blocks the first launch. Open Vitrel once,
then choose **Open Anyway** in System Settings ▸ Privacy & Security.

Uninstall with `brew uninstall --cask vitrel`; `brew uninstall --zap --cask vitrel` also removes its data.
